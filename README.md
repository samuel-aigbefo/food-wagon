
FoodWagon

FoodWagon is a full-stack food ordering application I built to simulate a real-world food delivery platform. The frontend was developed from a Figma design, while the backend was built with Node.js, Express, and MongoDB. The application includes a customer-facing website where users can browse meals, place orders, and track their purchases, along with a secure admin dashboard for managing products and orders.

A few things I enjoyed building

One of my favorite parts of this project was making the admin dashboard feel responsive without needing to refresh the page. For example, when an order status changes, the dashboard updates immediately, which made the app feel much closer to a real production system.

I'm also proud of how I structured the project. I focused on keeping components reusable, organizing the API cleanly, and separating frontend and backend responsibilities so the project would be easier to maintain as it grows.
